Plugin file format
---
title: My Plugin
layout: plugin
homepage: https://example.com
organization: My organization
organization_url: https://example.com
download_url: https://example.com/plugin.jar
download_version: "1.0"
download_description: "Release notes: what changed"
download_date: YYYY-MM-DD
license: Apache-2.0
developers: Developer names
sonarqube_version: "2025.2-LATEST"
category: external analysers
description: What the plugin does.
details: Additional information.
seo:
  name: My Plugin
  headline: My Plugin - SonarQube Plugin
  type: ItemPage
---

Name the file YYYY-MM-DD-myplugin.markdown. Quote values containing a colon followed by a space.
